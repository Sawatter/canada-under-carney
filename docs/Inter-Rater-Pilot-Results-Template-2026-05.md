## Scoring Key

| Comparison | Score |
|---|---:|
| Exact grade match, including plus/minus | 1 |
| Within one plus/minus step | 0.5 |
| Same broad letter band but not within one step | 0 |
| Different broad letter band | -1 |
| Same grade but different active-modifier set | 0 for modifier agreement; flag for review |

Rubric revision is triggered by any hard disagreement or aggregate score below 1. Protocol revision is triggered when the rater reports Low confidence because the packet was missing evidence or a rule needed for grading.
