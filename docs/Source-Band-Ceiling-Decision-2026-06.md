## Decision

Keep the current rule: **10 sources is the working ceiling for a dimension.** A dimension at 10 can add a new analytical source only if one of these is true:

1. An existing source is trimmed or swapped out in the same pass.
2. The new source is a missing primary source needed for traceability.
3. The editor explicitly approves a one-off relaxation and the changelog says why.

## Rationale

The dashboard needs enough sources for a reader to see the evidence mix, but a card with too many sources starts to read like a kitchen-sink archive instead of a usable scorecard. The 10-source ceiling is a readability rule and a source-role discipline, not a claim that ten is mathematically ideal.

This decision does not change any source array, grade, threshold, scoring rule, or source-order field.
